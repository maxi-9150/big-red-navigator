# GitHub Pages

The repository root is the deployment source for main / root. index.html, app.js, evidence.js, style.css, resources.json and bear.png form the static website. Relative asset paths support the /big-red-navigator/ project URL. .nojekyll bypasses Jekyll processing.

The online version uses browser-side evidence retrieval, not Python or an LLM. Feedback and resource plans stay in the visitor's browser. No secrets or backend service are needed. The Python development app remains in server.py and static/.
